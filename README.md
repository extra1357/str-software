# Strsoftware — Landing Page

Landing page de captura de leads para a Strsoftware, empresa de desenvolvimento de software sob demanda operada pela Cotawebseguros Ltda.

## Sobre

Página institucional com formulário de captação de clientes interessados em desenvolvimento de sistemas, marketplaces e plataformas digitais.

## Stack

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Prisma ORM

## Quick Start

```bash
npm install
cp .env.example .env
npx prisma migrate dev
npm run dev
```
